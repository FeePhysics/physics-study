# ดัชนีและหน่วยธรรมชาติ: 5/5 รวมข้อผสม — milestone แรกของ mission สำเร็จ

บทที่ 3 ได้ **5/5** · ข้อ 4 เป็น**ข้อผสม**ที่ต้องใช้เนอเธอร์ (บทที่ 2) กับดัชนี (บทที่ 3)
พร้อมกัน — ตอบถูก ⇒ นี่เป็นหลักฐานที่หนักกว่า 4/4 ของบทที่ 2 เพราะเป็น
**interleaved retrieval** ไม่ใช่การทวนเรื่องที่เพิ่งอ่านจบ

## Milestone

ผู้เรียนอ่าน $\mathcal{L} = \tfrac12\partial_\mu\phi\,\partial^\mu\phi - \tfrac12 m^2\phi^2$
**ออกทั้งบรรทัด** และบอกได้ว่าให้สมการไคลน์–กอร์ดอน · นี่คือข้อแรกใน "Success looks like"
ของ `MISSION.md` ที่เริ่มเป็นจริง — **แต่ยังไม่ได้ยืนยันกับ paper จริง**

## Implications

- **สูตรที่ใช้ได้ผล 3 รอบติด:** บทเรียนที่ยืนบนการคำนวณจริง → ทดสอบทันที →
  บทถัดไปแทรกข้อผสมของบทก่อน · ใช้ต่อไป ไม่ต้องเปลี่ยน
- บทที่ 4 (การแปรผัน + พจน์ขอบ) ปิดวงกลับไปที่บทที่ 1: เงื่อนไข "ปลายตรึง" ที่เคยเป็น
  แค่กติกา กลายเป็นสิ่งที่ทำให้ integration by parts ทำงานได้ ·
  **ของแถมที่ `sympy` เจอ:** $\eta = \sin(\pi t/2)$ ให้ $\int\eta f\,dt = 0$ ทั้งที่
  $f = t-1$ ไม่ใช่ศูนย์ ⇒ สาธิตได้ด้วยตัวเลขว่าทำไมบทตั้งหลักต้องพูดว่า "ทุก $\eta$"
- ⚠️ **คิวถัดไปคือเปิด paper จริง ซึ่งเป็นจุดที่ระบบนี้ยังทำเองไม่ได้** —
  proxy ของคลาวด์บล็อก arxiv.org ⇒ ผมโหลด paper มาอ่านให้ไม่ได้ ·
  ทางที่ทำได้: **ให้แบวาง abstract หรือย่อหน้าที่ติดมาในแชต** แล้วถอดรหัสด้วยกัน
  ทีละบรรทัด · หรือแบรัน Claude Code บนเครื่องตัวเองซึ่งเปิดเน็ตได้ตามปกติ
- ยังไม่ได้สอน: การอนุพันธ์เชิงแปรผันของสนามอย่างเป็นทางการ · สมมาตรภายใน (internal
  symmetry) กับ gauge · เทนเซอร์ความโค้ง · path integral (คำตอบว่าทำไมต้อง $T-V$
  ซึ่งค้างมาตั้งแต่บทที่ 1)
