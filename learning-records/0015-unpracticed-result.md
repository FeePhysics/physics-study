# 0015 · ผลบทซ่อม "กฎที่เคยพูดผ่าน ๆ"

**ผลที่รายงาน:** `ถูก 7/9 · ผิดข้อ 4 (ขั้น 1: Kx2-Kx3 · ขั้น 2: Kx2-Kx3) · 5 (ตอบ 2)`

## สามในสี่ปิดแล้ว

รอบก่อนวัดได้ว่ามีสี่ปฏิบัติการที่ **เคยถูกฝึก 0 ครั้ง** จากข้อฝึก 104 รายการ
และทั้งสี่คือข้อที่พลาดพอดี · รอบนี้:

| ปฏิบัติการ | รอบก่อน | รอบนี้ |
|---|---|---|
| กระจาย $V$ / สูตร $\varepsilon$ ฉบับกฎลูกโซ่ | ✗ | **✓ ผ่านครบ 5 ขั้น** |
| $V$ คนละแบบ (สปริง) | — | **✓** |
| คำนวณ $v^\mu v_\mu$ เป็นตัวเลข | ✗ | **✓ ทั้งสามข้อ** (28 · −2 · 0) |
| นับด้วยปฏิสมมาตร ($D=5$) | ✗ | **✓** |
| อ่าน $\eta$ ออกจากนิพจน์ | ✗ | **✓** |
| **ตรวจสมมาตร** | ✗ | **✗ ยังไม่ติด** |

⇒ **คำถาม "ต้องท่องไหม" ปิดแล้ว** — สูตร $\varepsilon$ ฉบับกฎลูกโซ่ใช้เดินได้จริง
ครบทั้งห้าขั้น และใช้กับ $V$ ที่ไม่เคยเจอได้ด้วย

## ข้อ 4 · คำตอบบอกตรงจุดมาก

ตอบ `Kx2-Kx3` ทั้งสองขั้น · เทียบด้วย sympy:

| | |
|---|---|
| $\partial L/\partial x_3$ | $Kx_2 - Kx_3$ — **ตรงกับที่ตอบเป๊ะ** |
| ผลรวมทั้งสามตัว | $0$ — ไม่ตรง |

**อนุพันธ์ย่อยไม่ผิดเลย ตัวที่สามถูกทุกตัวอักษร** · ขั้นที่หายไปคือ
"แล้วบวกอีกสองตัวเข้าไปด้วย"

### ต้นเหตุเชิงออกแบบ

ผมเขียนตัวตรวจเป็น $\sum_i (\partial L/\partial x_i)\delta x_i$ แล้ว
**ให้ตอบทั้งก้อนในช่องเดียว** โดยไม่เคยมีข้อไหนให้ลงมือทีละตัวมาก่อนเลย

· ทุกที่ที่เคยไล่ทีละขั้นได้ผล (ข้อ 1, 2, 3 ของรอบนี้ ผ่านหมด)
· ทุกที่ที่รวบเป็นช่องเดียว พัง
· และ $\sum_i$ ตัวนี้ยัง**ชนกับกฎรวมของไอน์สไตน์ในบทที่ 3** ซึ่งสอนว่า
  "ดัชนีซ้ำ = รวมอัตโนมัติ ไม่ต้องเขียน $\sum$" — คนละเรื่องกันแต่หน้าตาใกล้กันมาก

## ข้อ 5 · ตอบ 2 = จำนวนอนุภาค

ไม่ใช่ความเข้าใจผิดอิสระ — **เมื่อตัวตรวจยังใช้ไม่เป็น สิ่งที่เหลือให้นับก็มีแต่
จำนวนอนุภาค** ⇒ สองข้อนี้เป็นอาการเดียวกัน ไม่ใช่สองเรื่อง

## บทฝึก `0014-symcheck.html`

**ปฏิบัติการเดียว 7 ข้อ** — ไม่มีเนื้อหาใหม่เลย มีแต่การลงมือ

· ข้อ 1–3 เป็นแบบไล่ขั้น **บังคับให้หา $\partial L/\partial x_i$ ทีละตัวก่อน แล้วค่อยบวก**
  (ข้อ 3 คือระบบเดิมที่พลาด — ขั้นที่ 3 ของมันคือคำตอบที่แบให้มาพอดี และเฉลยบอกไว้ตรง ๆ)
· ข้อ 1 กับ 2 เป็นระบบเดียวกันต่างกันพจน์เดียว แต่คำตอบคนละขั้ว (สมมาตร vs ไม่มีเลย)
  — **สิ่งเดียวที่แยกสองข้อออกจากกันคือขั้นบวก**
· กางสมการ (1) ออกเป็นสามพจน์ให้เห็นแทนการใช้ $\sum$ และเตือนว่า $i$ ตรงนี้
  ไม่ใช่ดัชนีกาลอวกาศแบบบทที่ 3
· ของแถมที่ทำให้เดาผลได้ก่อนคำนวณ: **พจน์สปริงระหว่างคู่หักล้างกันเองเสมอ
  ที่รอดจากการบวกคือพจน์ที่ยึดกับพื้น**
· ข้อ 4–7 เปลี่ยนขนาดระบบ (2, 3, 4 อนุภาค · 2 และ 3 มิติ) เพื่อทุบความเชื่อ
  "จำนวนปริมาณอนุรักษ์ = จำนวนอนุภาค": คำตอบออกมา 0, 1 และสูตร สลับกันไป
