## บทที่ 7 · จากอนุภาคไปสนาม

`0016-fields.html` · **5 สมการตั้งเลข · 8 ข้อฝึก 13 ช่องคำตอบ**

เส้นทาง: พจนานุกรมสองคอลัมน์ ($q(t)\to\phi(x^\mu)$ · $d/dt \to \partial_\mu$) →
เครื่องหมายเมตริก → สมการ EL ของสนาม → ไคลน์–กอร์ดอน → $\omega^2 = k^2+m^2$

**ผลตอบแทนของบท:** $E^2 = p^2 + m^2$ ตกลงมาจากลากรองจ์สองพจน์ ·
เลข $m$ ที่เขียนลงไปเฉย ๆ กลายเป็นมวลนิ่งจริง ๆ · และ $m=0 \Rightarrow$ ความเร็ว $= c$
ซึ่งอธิบายว่าคำว่า "โฟตอนไร้มวล" ของบทที่ 5 แปลว่าอะไรทางกายภาพ

### จุดเสี่ยงที่สุดของบทนี้คือเครื่องหมาย — ตรวจเป็นองค์ประกอบทุกตัว

`scripts/verify/0017_fields.py` คำนวณทุกอย่าง**เป็นองค์ประกอบจริง** ไม่ใช่พีชคณิตดัชนีในหัว:

- $\partial_\mu\phi\partial^\mu\phi = -\dot\phi^2 + |\nabla\phi|^2$ ✓
- $\mathcal{L} = -\tfrac12\partial_\mu\phi\partial^\mu\phi - \tfrac12m^2\phi^2$
  กางออกได้รูป $T-V$ จริง ✓ · และแสดงด้วยว่าถ้าเขียน $+\tfrac12$ จะได้**พจน์จลน์ติดลบ**
- $\partial\mathcal{L}/\partial(\partial_\mu\phi) = -\partial^\mu\phi$ ครบทั้งสี่องค์ประกอบ ✓
- EL ประกอบแล้วได้ $\Box\phi = m^2\phi$ ✓ · แทนคลื่นระนาบได้ $\omega^2=k^2+m^2$ ✓
- ⚠️ **เช็คความเข้ากันกับบทที่ 5**: $-\tfrac14F_{\mu\nu}F^{\mu\nu} = \tfrac12(E^2-B^2)$
  (สร้าง $F$ จาก $A_\mu$ จริงแล้วหดดัชนี) ⇒ **ไม่ขัดกับบทเก่า** ·
  และ $F$ มีสองดัชนี การพลิกเครื่องหมายสองครั้งหักกันเอง ⇒ $-\tfrac14F^2$
  เขียนเหมือนกันทั้งสอง signature ต่างจากพจน์ของ $\phi$ — **เขียนเตือนไว้ในบทแล้ว**
  เพราะเป็นจุดที่อ่าน paper แล้วสับสนได้
