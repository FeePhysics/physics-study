# เริ่มชุดรังนกพิราบ — แบรู้หลักการแล้ว สิ่งที่ขาดคือการสร้างรังและการเขียนพิสูจน์

แบเป็นครูคณิตและมีเอกสารค่าย 2 (ภาขวัญ) ซึ่งสอนหลักการแบบง่าย/ทั่วไป/ฟังก์ชันครบ จึงไม่สอนหลักการซ้ำ
P1 เน้นโครงสี่ส่วนของข้อพิสูจน์ และ "น้อยที่สุด = ตัวอย่างที่ไม่พอ + การรับประกัน" · ผลรอบแรกของ P1: **ยังรอผล**

**Implications:** ถ้า P1 ผ่านเร็ว ให้ข้ามไป P2 ได้ทันที · จุดที่ต้องระวังคือข้อ 5–6 (หาที่ผิด) ซึ่งวัดว่าตรวจรังของตัวเองได้หรือไม่
