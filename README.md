# physics-study

Teaching workspace สำหรับศึกษาฟิสิกส์ทฤษฎีอย่างเป็นระบบ — ขับด้วยสกิล `/teach`
ของ Claude Code

## เริ่มยังไง

```bash
pip install -r requirements.txt
claude          # หรือเปิด claude.ai/code แล้วเลือก repo นี้
```

จากนั้นพิมพ์:

```
/teach ฟิสิกส์ทฤษฎี
```

บทแรกสกิลจะ **ถามก่อนว่าทำไมถึงอยากเรียน** เพื่อเขียน `MISSION.md` —
ตอบให้ตรงและเจาะจง (เป้าหมายจริง กรอบเวลาจริง) เพราะทุกบทเรียนหลังจากนั้น
จะถูก ground ด้วยไฟล์นี้ ตอบลอย ๆ แล้วบทเรียนจะลอยตาม

## อ่านอะไรก่อน

| ไฟล์ | คืออะไร |
|---|---|
| `MISSION.md` | เหตุผลที่เรียน — ยังไม่มีจนกว่าจะเริ่มบทแรก |
| `learning-records/` | เรียนอะไรไปแล้ว · ใช้ตัดสินว่าบทต่อไปควรเป็นอะไร |
| `reference/` | ชีทสรุปที่กลับมาเปิดซ้ำ (บทเรียนไม่ค่อยถูกเปิดซ้ำ) |
| `lessons/` | บทเรียนทั้งหมด เรียงตามลำดับที่เรียน |

รายละเอียดกฎของ workspace อยู่ใน [CLAUDE.md](./CLAUDE.md)
