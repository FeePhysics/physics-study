§2.1.1 The Metric · หน้า 24–27

ตัวเลขพิกัดบอกแค่ว่าเราอยู่ "ช่องไหน" ไม่ได้บอกว่าห่างกันจริงเท่าไร ตัวที่แปลงผลต่างของพิกัดเป็นระยะจริงคือ metric ตัวอย่างที่ผู้เรียนคุ้นที่สุดคือระนาบ: ในพิกัดฉาก ระยะกำลังสองระหว่างจุดใกล้กันคือ $dx^2 + dy^2$ แต่ในพิกัดเชิงขั้ว ระยะกำลังสองคือ $dr^2 + r^2d\theta^2$ — ไม่ใช่ $dr^2 + d\theta^2$ เพราะการขยับมุม $d\theta$ ที่รัศมี $r$ คือการเดินระยะ $r\,d\theta$ ระยะที่ได้เป็น invariant: คนใช้พิกัดฉากกับคนใช้พิกัดขั้วได้ตัวเลขเดียวกัน

เขียนรวมเป็น $dl^2 = \sum_{i,j} g_{ij}\,dx^i dx^j$ โดย $g_{ij}$ เป็นเมทริกซ์สมมาตร 2×2: พิกัดฉาก $g = {\rm diag}(1, 1)$ · พิกัดขั้ว ($x^1 = r$, $x^2 = \theta$) $g = {\rm diag}(1, r^2)$ รูป 2.1 (แผนที่เส้นชั้นความสูงของภูเขา มีเส้นทางเดินสองเส้นที่ยาวเท่ากันบนกระดาษ) ให้ภาพว่า "ความยาวจริง" ของเวกเตอร์ต้องรู้ metric — เส้นที่ตัดเส้นชั้นความสูงถี่กว่าเดินเหนื่อยกว่า

ข้อดีใหญ่ของ metric คือมันดูดแรงโน้มถ่วงเข้าไปไว้ข้างใน: แทนที่จะพูดว่าอนุภาคถูกแรงดึง ให้พูดว่าอนุภาคเดินอิสระในกาลอวกาศที่ metric ไม่สามารถแปลงเป็นแบบแบนได้ทุกที่

$$ds^2 = \sum_{\mu,\nu=0}^{3} g_{\mu\nu}\,dx^\mu dx^\nu$$

อ่านว่า $\mu, \nu$ วิ่ง 0–3 โดย $x^0 = t$ และ $x^{1,2,3}$ เป็นพิกัดอวกาศ · $g_{\mu\nu}$ = metric 4×4 สมมาตร (สูงสุด 10 ตัวที่อิสระ) · $ds^2$ = interval · หลังสมการนี้หนังสือเลิกเขียน $\sum$ — ดัชนีซ้ำบนล่างคือบวก

$$\eta_{\mu\nu} = {\rm diag}(-1,\ 1,\ 1,\ 1)$$

อ่านว่า Minkowski metric ของ special relativity (หนังสือเขียนเป็นเมทริกซ์ 4×4) · signature $(-,+,+,+)$ ตรงกับบทเรียน QFT ส่วนใหญ่ใน repo นี้ แต่ตรงข้ามกับ Tong

เมื่อกริดยืดด้วย $a(t)$ ระยะในอวกาศต้องคูณ $a$ แต่เวลาไม่เปลี่ยน จึงเดาได้ว่า metric ของเอกภพแบนที่ขยายตัวคือ

$$g_{\mu\nu} = {\rm diag}\big(-1,\ a^2(t),\ a^2(t),\ a^2(t)\big)$$

อ่านว่า นี่คือ Friedmann–Robertson–Walker (FRW) metric แบบ flat · แปลเป็น interval: $ds^2 = -dt^2 + a^2(t)\,(dx^2 + dy^2 + dz^2)$ โดย $x, y, z$ เป็น comoving coordinates · $a$ ขึ้นกับ $t$ อย่างเดียว ไม่ขึ้นกับตำแหน่ง (เอกภพเรียบ)

กล่อง Indices (หน้า 27) ทบทวน index notation ซึ่งผู้เรียนรู้แล้ว ยกเว้นสองเรื่องที่ควรอ่านช้า ๆ: ดัชนีบนคือเวกเตอร์ ดัชนีล่างคือ "1-form" และ metric เป็นตัวสลับระหว่างสองแบบ

$$A_\mu = g_{\mu\nu}A^\nu \quad ; \quad A^\mu = g^{\mu\nu}A_\nu$$
$$g^{\nu\beta}g_{\alpha\beta} = \delta^\nu{}_\alpha$$

อ่านว่า $g^{\mu\nu}$ (ดัชนีบนทั้งคู่) คือเมทริกซ์ผกผันของ $g_{\mu\nu}$ · $\delta^\nu{}_\alpha$ = Kronecker delta (1 ถ้า $\nu = \alpha$ ไม่งั้น 0) คือเมทริกซ์เอกลักษณ์ · สำหรับ FRW: $g^{\mu\nu} = {\rm diag}(-1, a^{-2}, a^{-2}, a^{-2})$ เพราะผกผันเมทริกซ์ทแยงคือกลับเศษเป็นส่วนทีละตัว · สมการ (2.8) ในกล่องเดียวกัน $P^2 \equiv g_{\mu\nu}P^\mu P^\nu = 0$ คือเงื่อนไขของอนุภาคไร้มวล

§2.1.2 The Geodesic Equation · หน้า 28–31

ในกาลอวกาศแบน อนุภาคที่ไม่มีแรงกระทำเดินเป็นเส้นตรง ภาษาทั่วไปของ "เส้นตรง" ในกาลอวกาศโค้งเรียก geodesic หนังสือสร้างสมการนี้ด้วยเทคนิคที่ฉลาด: เริ่มจากระนาบแบนธรรมดา แต่ใช้พิกัดเชิงขั้ว

$$\frac{d^2x^i}{dt^2} = 0$$

อ่านว่า อนุภาคอิสระในพิกัดฉาก $x^i = (x, y)$ — ความเร่งศูนย์ทุกแกน · แต่ในพิกัดขั้ว $x'^i = (r, \theta)$ อนุภาคที่วิ่งเป็นเส้นตรงไม่ได้มี $\ddot r = 0$ และ $\ddot\theta = 0$ (ลองนึกเส้นตรงที่ผ่านใกล้จุดกำเนิด: $r$ ลดแล้วเพิ่ม มุมเปลี่ยนเร็วตอนใกล้ — ทั้งคู่มีความเร่ง) สาเหตุคือเวกเตอร์ฐาน $\hat r, \hat\theta$ หมุนไปตามตำแหน่ง

วิธีหาสมการในพิกัดใหม่: เขียน $dx^i/dt$ ด้วย chain rule ผ่าน transformation matrix $\partial x^i/\partial x'^j$ แล้วหาอนุพันธ์เทียบเวลาอีกครั้ง ซึ่งต้องทำ product rule เพราะตัว matrix เองก็เปลี่ยนไปตามเส้นทาง (ถ้าการแปลงเป็นเชิงเส้น matrix คงที่และไม่มีพจน์เกิน) ผลคือ (2.16) ซึ่งมีพจน์ $\ddot x'$ คูณ matrix บวกพจน์ที่มีอนุพันธ์อันดับสองของการแปลง จากนั้นคูณด้วย matrix ผกผันเพื่อให้ $\ddot x'$ อยู่ลำพัง ได้

$$\frac{d^2x'^l}{dt^2} + \left[\left(\left\{\frac{\partial x}{\partial x'}\right\}^{-1}\right)^l{}_i\,\frac{\partial^2 x^i}{\partial x'^j\partial x'^k}\right]\frac{dx'^k}{dt}\frac{dx'^j}{dt} = 0$$

อ่านว่า ก้อนในวงเล็บเหลี่ยมคือ Christoffel symbol $\Gamma^l{}_{jk}$ (นิยามว่าเป็นสัมประสิทธิ์หน้าความเร็วสองตัว) · สมมาตรในดัชนีล่าง $j, k$ เพราะอนุพันธ์ย่อยสลับลำดับได้ · ในพิกัดฉาก $\Gamma = 0$ สมการกลับเป็น (2.11)

ตัวอย่างที่หนังสือยกไปไว้ในโจทย์ข้อ 2 — Γ ของพิกัดขั้ว

หนังสือให้คำตอบไว้ในตัวโจทย์ (2.92): ตัวที่ไม่เป็นศูนย์มีแค่ $\Gamma^r{}_{\theta\theta} = -r$ และ $\Gamma^\theta{}_{r\theta} = \Gamma^\theta{}_{\theta r} = 1/r$ (สคริปต์ตรวจแล้วว่าได้ชุดเดียวกันทั้งจากวงเล็บใน (2.17) และจากสูตร (2.19) ข้างล่าง และว่าเส้นตรง $y = b$ เป็นคำตอบของสมการที่ได้จริง) ส่วนการเขียนสมการเคลื่อนที่สองสมการแล้วตีความ เป็นงานของโจทย์ข้อ 2(b) — ใบ้ว่าตัวหนึ่งคือแรงหนีศูนย์กลาง อีกตัวคือการอนุรักษ์โมเมนตัมเชิงมุม

ยกไปใช้ในสัมพัทธภาพต้องเปลี่ยนสองอย่าง: ดัชนีวิ่ง 0–3 และเลิกใช้ $t$ เป็นตัวแปรเดินเพราะ $t$ กลายเป็นพิกัดตัวหนึ่ง ใช้พารามิเตอร์ $\lambda$ ที่เพิ่มขึ้นเรื่อย ๆ ตามเส้นทางแทน (รูป 2.2: เส้นทางจาก $x^\mu(\lambda_i)$ ถึง $x^\mu(\lambda_f)$)

$$\frac{d^2x^\mu}{d\lambda^2} = -\Gamma^\mu{}_{\alpha\beta}\,\frac{dx^\alpha}{d\lambda}\frac{dx^\beta}{d\lambda}$$
$$\Gamma^\mu{}_{\alpha\beta} = \frac{g^{\mu\nu}}{2}\left[\frac{\partial g_{\alpha\nu}}{\partial x^\beta} + \frac{\partial g_{\beta\nu}}{\partial x^\alpha} - \frac{\partial g_{\alpha\beta}}{\partial x^\nu}\right]$$

อ่านว่า (2.18) คือ geodesic equation: "ความเร่ง" ของพิกัดเกิดจาก Γ ล้วน ๆ ไม่มีแรง · (2.19) คำนวณ Γ จาก metric ตรง ๆ โดยไม่ต้องรู้การแปลงพิกัดจากระบบฉาก ซึ่งในเอกภพที่ขยายตัวหาไม่ได้อยู่แล้ว · สังเกตลวดลาย: อนุพันธ์สามตัวที่ดัชนีหมุนเวียน ตัวสุดท้ายติดลบ · $\nu$ เป็นดัชนีที่ถูกบวก

แทน FRW (2.4) ลงใน (2.19): metric ทแยงจึง $g^{0\nu}$ ไม่เป็นศูนย์เฉพาะ $\nu = 0$ (มีค่า $-1$) และ $g_{00} = -1$ คงที่ อนุพันธ์ของมันเป็นศูนย์ เหลือพจน์เดียวที่มาจาก $\partial g_{ij}/\partial t$

$$\Gamma^0{}_{00} = 0, \qquad \Gamma^0{}_{0i} = \Gamma^0{}_{i0} = 0, \qquad \Gamma^0{}_{ij} = \delta_{ij}\,\dot a a$$
$$\Gamma^i{}_{0j} = \Gamma^i{}_{j0} = \delta_{ij}\,\frac{\dot a}{a}$$

(หนังสือบอกว่า $\Gamma^i{}_{\alpha\beta}$ ตัวอื่นเป็นศูนย์ทั้งหมด)

อ่านว่า จุดบน $\dot a$ = อนุพันธ์เทียบ $t$ (เชิงอรรถหน้า 30: ตั้งแต่บทที่ 4 จุดจะหมายถึงอนุพันธ์เทียบ conformal time แทน — ระวัง) · ดัชนีโรมัน $i, j$ = อวกาศ 1–3 · ดัชนีกรีก = 0–3 · $\delta_{ij}$ = Kronecker delta

ขั้นที่หนังสือข้าม — $\Gamma^0{}_{ij}$ และ $\Gamma^i{}_{0j}$

$\Gamma^0{}_{ij}$: ใน (2.19) ใส่ $\mu = 0$ ⇒ เหลือ $\nu = 0$ และ $g^{00} = -1$ · สองพจน์แรกมี $g_{i0}, g_{j0}$ ซึ่งเป็นศูนย์ · พจน์ที่สาม $-\partial g_{ij}/\partial t = -\delta_{ij}\,2a\dot a$ · รวม: $\tfrac{-1}{2}(-2a\dot a\,\delta_{ij}) = \delta_{ij}a\dot a$ ✓

$\Gamma^i{}_{0j}$: ใส่ $\mu = i$ ⇒ $\nu = i$ และ $g^{ii} = a^{-2}$ · พจน์แรก $\partial g_{0i}/\partial x^j = 0$ · พจน์ที่สอง $\partial g_{ji}/\partial t = \delta_{ij}2a\dot a$ · พจน์ที่สาม $\partial g_{0j}/\partial x^i = 0$ · รวม: $\tfrac{a^{-2}}{2}\cdot 2a\dot a\,\delta_{ij} = \delta_{ij}\dot a/a$ ✓ (ส่วน $\Gamma^i{}_{jk}$ ศูนย์เพราะ metric ไม่ขึ้นกับ $x, y, z$)

ใช้ geodesic กับโฟตอน (หน้า 31). ให้ $P^\alpha = (E, \vec P)$ เป็น four-momentum และใช้มันนิยาม $\lambda$ โดยปริยาย

$$P^\alpha = \frac{dx^\alpha}{d\lambda}$$

อ่านว่า $E = P^0$ คือพลังงาน · $\vec P$ เป็นโมเมนตัมบนกริด comoving (เชิงอรรถ 2: โมเมนตัมจริงต่างจากมันด้วยตัวคูณ $a$) · เราไม่ต้องหา $\lambda$ จริง เพราะ $d/d\lambda = (dx^0/d\lambda)\,d/dx^0 = E\,d/dt$ (2.25)

ส่วนเวลาของ (2.18) กลายเป็น $E\,dE/dt = -\Gamma^0{}_{ij}P^iP^j$ (2.26) แล้วใช้เงื่อนไขไร้มวล

$$g_{\mu\nu}P^\mu P^\nu = -E^2 + \delta_{ij}a^2P^iP^j = 0$$
$$\frac{dE}{dt} + \frac{\dot a}{a}E = 0 \quad\Longrightarrow\quad E \propto \frac{1}{a}$$

ขั้นที่หนังสือข้าม — จาก (2.26) ถึง (2.28)

ขวามือของ (2.26): แทน (2.22) ได้ $-\delta_{ij}a\dot a P^iP^j$ · จาก (2.27) $\delta_{ij}P^iP^j = E^2/a^2$ · ดังนั้นขวามือ $= -a\dot a\,E^2/a^2 = -(\dot a/a)E^2$ · หารสองข้างด้วย $E$ ได้ (2.28) · แก้: $dE/E = -da/a$ ⇒ $\ln E = -\ln a + $ ค่าคงตัว ⇒ $E \propto 1/a$ (2.29) — ยืนยันการโบกมือของบทที่ 1 ว่าพลังงานโฟตอนลดตามความยาวคลื่นที่ถูกยืด

§2.1.3 Einstein Equations · หน้า 32–33

ผู้เขียนชี้จุดที่น่าสนใจ: metric กับ geodesic เป็นเรขาคณิตล้วน ไม่ต้องใช้ GR เลย ส่วนที่เป็น GR จริงมีสองข้อ คือ (ก) ความโน้มถ่วงบรรยายได้ด้วย metric และ (ข) metric ถูกกำหนดโดยพลังงานผ่านสมการ Einstein

$$G_{\mu\nu} \equiv R_{\mu\nu} - \frac12 g_{\mu\nu}\mathcal{R} = 8\pi G\,T_{\mu\nu}$$

อ่านว่า $G_{\mu\nu}$ = Einstein tensor (ฝั่งเรขาคณิต) · $R_{\mu\nu}$ = Ricci tensor สร้างจาก metric และอนุพันธ์ · $\mathcal{R} \equiv g^{\mu\nu}R_{\mu\nu}$ = Ricci scalar (หดดัชนีให้เหลือตัวเลขตัวเดียว) · $G$ ตัวเดียวไม่มีดัชนี = ค่าคงตัวของนิวตัน (คนละตัวกับ $G_{\mu\nu}$!) · $T_{\mu\nu}$ = energy-momentum tensor (ฝั่งพลังงาน) — สมการนี้คือ "เรขาคณิต = พลังงาน" เขียนเป็นเทนเซอร์

$$R_{\mu\nu} = \Gamma^\alpha{}_{\mu\nu,\alpha} - \Gamma^\alpha{}_{\mu\alpha,\nu} + \Gamma^\alpha{}_{\beta\alpha}\Gamma^\beta{}_{\mu\nu} - \Gamma^\alpha{}_{\beta\nu}\Gamma^\beta{}_{\mu\alpha}$$

อ่านว่า จุลภาคในตัวห้อยแปลว่าอนุพันธ์ย่อย: $\Gamma^\alpha{}_{\mu\nu,\alpha} \equiv \partial\Gamma^\alpha{}_{\mu\nu}/\partial x^\alpha$ (และ $\alpha$ ซ้ำจึงบวก 0–3) · สองพจน์แรกเป็นอนุพันธ์ของ Γ สองพจน์หลังเป็นผลคูณ Γ·Γ · คู่มือนี้ไม่อธิบายว่าทำไม Ricci หน้าตาแบบนี้ (เป็นเรื่องความโค้งใน GR — ยังไม่ได้สอน) ใช้เป็นสูตรแทนค่าเหมือนหนังสือ

ผลจาก FRW: Ricci ที่ไม่เป็นศูนย์มีแค่ส่วน 00 กับส่วน $ij$

$$R_{00} = -3\frac{\ddot a}{a}$$
$$R_{ij} = \delta_{ij}\left[2\dot a^2 + a\ddot a\right]$$
$$\mathcal{R} = 6\left[\frac{\ddot a}{a} + \left(\frac{\dot a}{a}\right)^2\right]$$

ขั้นที่หนังสือข้าม — $R_{00}$ ทีละพจน์ (หน้า 32–33)

ใส่ $\mu = \nu = 0$ ใน (2.31): พจน์ที่ 1 และ 3 มี $\Gamma^\cdot{}_{00}$ ซึ่งเป็นศูนย์ทั้งหมด · พจน์ที่ 2 $-\partial_t\Gamma^\alpha{}_{0\alpha}$: ไม่ศูนย์เฉพาะ $\alpha = i$ ได้ $-\partial_t(\delta_{ii}\dot a/a)$ · $\delta_{ii}$ (บวก $i$) $= 3$ ⇒ $-3(\ddot a/a - \dot a^2/a^2)$ · พจน์ที่ 4 $-\Gamma^\alpha{}_{\beta0}\Gamma^\beta{}_{0\alpha}$: ไม่ศูนย์เฉพาะ $\alpha = i, \beta = j$ ได้ $-(\dot a/a)^2\delta_{ij}\delta_{ij} = -3(\dot a/a)^2$ · รวม: $-3\ddot a/a + 3\dot a^2/a^2 - 3\dot a^2/a^2 = -3\ddot a/a$ ✓

Ricci scalar: $\mathcal{R} = g^{00}R_{00} + g^{ii}R_{ii} = 3\ddot a/a + 3(2\dot a^2 + a\ddot a)/a^2 = 6\ddot a/a + 6\dot a^2/a^2$ ✓ (ส่วน $R_{ij}$ ทั้งหมดเป็นโจทย์ข้อ 5 — สคริปต์ตรวจผล (2.35) แล้ว)

$$\left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho$$
$$\frac{H^2(t)}{H_0^2} = \frac{\rho}{\rho_{\rm cr}}$$

อ่านว่า นี่คือ Friedmann equation ของเอกภพ flat · $\rho$ = ความหนาแน่นพลังงานรวมทุกชนิด · (2.40) ได้จากหาร (2.39) ด้วย $H_0^2$ แล้วใช้ $\rho_{\rm cr} = 3H_0^2/8\pi G$ · ไม่มีพจน์ความโค้งเพราะเริ่มจาก metric แบน — กรณีเปิดเป็นโจทย์ข้อ 8

ขั้นที่หนังสือข้าม — ส่วน 00 ของ (2.30)

$G_{00} = R_{00} - \tfrac12 g_{00}\mathcal{R} = -3\ddot a/a + \tfrac12\cdot 6(\ddot a/a + \dot a^2/a^2) = 3\dot a^2/a^2$ — พจน์ $\ddot a$ ตัดกันหมด เหลือแต่ความเร็ว · ฝั่งขวา: $T_{00}$ (ดัชนีล่างทั้งคู่) $= \rho$ · ระวังว่า (2.51) เขียน $T^0{}_0 = -\rho$ ซึ่งไม่ขัดกัน เพราะ $T_{00} = g_{00}T^0{}_0 = (-1)(-\rho) = \rho$ · ได้ $3\dot a^2/a^2 = 8\pi G\rho$ ⇒ (2.39)

§2.2 Distances · หน้า 33–37

ในเอกภพที่ขยายตัว "ระยะทาง" มีหลายนิยาม เพราะแสงออกจากต้นทางตอน $a$ เล็กแต่มาถึงเราตอน $a = 1$ ตัวตั้งต้นที่ใช้สร้างทุกตัวคือระยะบนกริด comoving ซึ่งในเอกภพ flat คือ Pythagoras ธรรมดา แสงใช้เวลา $dt$ เดินระยะจริง $dt$ (เพราะ $c = 1$) จึงเดินบนกริดได้ $dt/a$

$$\eta \equiv \int_0^t \frac{dt'}{a(t')}$$

อ่านว่า $\eta$ = ระยะ comoving ที่แสงเดินได้ตั้งแต่ $t = 0$ — ไกลกว่านี้ไม่มีข้อมูลใดส่งถึงกันได้ จึงเรียก comoving horizon · เพราะ $\eta$ เพิ่มขึ้นตลอด จึงใช้เป็นตัวแปรเวลาได้ด้วย เรียก conformal time (ทั้งเล่มหลังจากนี้ใช้ $\eta$ แทน $t$ บ่อยมาก) · หน้า 34 บอกผล: $\eta \propto a^{1/2}$ ในยุค matter และ $\eta \propto a$ ในยุค radiation

$$\chi(a) = \int_{t(a)}^{t_0}\frac{dt'}{a(t')} = \int_a^1 \frac{da'}{a'^2H(a')}$$

อ่านว่า $\chi$ (ไค) = comoving distance จากเราถึงวัตถุที่เปล่งแสงตอน scale factor เป็น $a$ (หรือ redshift $z = 1/a - 1$) · ตัวแปรที่มี prime เป็นตัวแปรอินทิเกรต

ขั้นที่หนังสือข้าม — เปลี่ยนตัวแปรใน (2.42) และ (2.43)

$da/dt = aH$ ⇒ $dt = da/(aH)$ ⇒ $dt/a = da/(a^2H)$ · ขอบเขต $t(a) \to t_0$ กลายเป็น $a \to 1$ ✓

ยุค matter ล้วน: $H = H_0a^{-3/2}$ (จาก (2.40) กับ $\rho \propto a^{-3}$) ⇒ อินทิแกรนด์ $= a'^{-1/2}/H_0$ · อินทิเกรต: $\chi = (2/H_0)[1 - a^{1/2}]$ · แทน $a = 1/(1+z)$ ได้

$$\chi^{\rm Flat,MD}(a) = \frac{2}{H_0}\left[1 - a^{1/2}\right] = \frac{2}{H_0}\left[1 - \frac{1}{\sqrt{1+z}}\right]$$

อ่านว่า MD = matter-dominated · $z$ เล็ก: กระจายได้ $\chi \approx z/H_0$ (กฎ Hubble กลับมา) · $z \to \infty$: $\chi \to 2/H_0$

Angular diameter distance. วัตถุขนาดจริง $l$ ที่เห็นเป็นมุม $\theta$ (เล็ก) นิยามระยะ

$$d_A = \frac{l}{\theta}$$
$$d_A^{\rm flat} = a\chi = \frac{\chi}{1+z}$$

อ่านว่า ขนาดบนกริดของวัตถุคือ $l/a$ และอยู่ห่าง $\chi$ บนกริด จึงเห็นมุม $\theta = (l/a)/\chi$ · เทียบกับ (2.44) ได้ $d_A = a\chi$ · ผลแปลก: ที่ $z$ สูงมาก $d_A$ ลดลง วัตถุไกลมากจึงดูใหญ่กว่าวัตถุที่ไกลปานกลาง (ในเอกภพ flat)

$$d_A = \frac{a}{H_0\sqrt{|\Omega_k|}}\begin{cases}\sinh\!\big[\sqrt{\Omega_k}H_0\chi\big] & \Omega_k > 0\\ \sin\!\big[\sqrt{-\Omega_k}H_0\chi\big] & \Omega_k < 0\end{cases}$$

อ่านว่า $\Omega_k \equiv 1 - \Omega_0$ = curvature density · $\Omega_0$ = ความหนาแน่นรวมวันนี้หารด้วย $\rho_{\rm cr}$ · $\Omega_k > 0$ คือ open · เมื่อ $\Omega_k \to 0$ ทั้งสองแถวกลับเป็น $a\chi$ (เพราะ $\sinh u \approx \sin u \approx u$ เมื่อ $u$ เล็ก)

Luminosity distance. ถ้าไม่มีการขยายตัว แหล่งกำเนิดกำลัง $L$ ให้ flux $F = L/4\pi d^2$ (2.47) ในเอกภพที่ขยายตัว ให้แหล่งอยู่ที่จุดกำเนิดของกริดแล้วมองเปลือกทรงกลม comoving รัศมี $\chi$ ที่เราอยู่: จำนวนโฟตอนที่ผ่านเปลือกต่อหน่วยเวลาลดลงด้วยตัวคูณ $a$ และพลังงานต่อโฟตอนลดลงอีกตัวคูณ $a$ (เชิงอรรถ 3: สมมติเครื่องวัดนับโฟตอนทุกความยาวคลื่น)

$$F = \frac{La^2}{4\pi\chi^2(a)}$$
$$d_L \equiv \frac{\chi}{a}$$

อ่านว่า นิยาม $d_L$ ให้สูตรเก่า $F = L/4\pi d_L^2$ ใช้ได้ต่อ · แทน (2.49) แล้วแก้ได้ $d_L = \chi/a$ · (นอกหนังสือแต่ตามมาทันที: $d_L/d_A = 1/a^2 = (1+z)^2$)

รูป 2.3 (แกนนอน $z$ 0.1–10, แกนตั้งระยะในหน่วย $1/H_0$) วาดสามระยะ $d_L$, $\chi$, $d_A$ จากบนลงล่าง แต่ละตัวมีสองเส้น: matter ล้วน กับ $\Lambda$ 70% · ทุกระยะยาวกว่าเมื่อมี $\Lambda$ เพราะ $\rho$ ในอดีตน้อยกว่า เอกภพจึงขยายช้ากว่า แสงมีเวลาเดินนานกว่า วัตถุไกลจึงดูจางกว่า

§2.3 Evolution of Energy · หน้า 37–40

ฝั่งขวาของสมการ Einstein ในเอกภพเรียบคือของไหลสมบูรณ์ (perfect fluid) ที่ไม่มีทิศพิเศษ

$$T^\mu{}_\nu = {\rm diag}\big(-\rho,\ \mathcal{P},\ \mathcal{P},\ \mathcal{P}\big)$$

อ่านว่า $\rho$ = ความหนาแน่นพลังงาน · $\mathcal{P}$ = ความดัน · ดัชนีบนหนึ่งล่างหนึ่ง (mixed) ทำให้ช่อง 00 ติดลบ

ในกาลอวกาศแบนที่ไม่มีแรงโน้มถ่วง การอนุรักษ์คือ $\partial T^\mu{}_\nu/\partial x^\mu = 0$ (สอนแล้วในบทที่ 9) แต่ในเอกภพที่ขยายตัว ต้องเปลี่ยนอนุพันธ์ธรรมดาเป็น covariant derivative ซึ่งเติมพจน์ Γ เข้าไปชดเชยที่ฐานพิกัดเปลี่ยนไปตามที่

$$T^\mu{}_{\nu;\mu} \equiv \frac{\partial T^\mu{}_\nu}{\partial x^\mu} + \Gamma^\mu{}_{\alpha\mu}T^\alpha{}_\nu - \Gamma^\alpha{}_{\nu\mu}T^\mu{}_\alpha = 0$$

อ่านว่า เซมิโคลอน ";" = covariant derivative (คู่กับจุลภาค "," = อนุพันธ์ธรรมดา) · ดัชนีบนแต่ละตัวได้พจน์ $+\Gamma$ ดัชนีล่างแต่ละตัวได้พจน์ $-\Gamma$ · เป็นสี่สมการ ($\nu = 0..3$) หนังสือใช้แค่ $\nu = 0$

$$\frac{\partial\rho}{\partial t} + \frac{\dot a}{a}\left[3\rho + 3\mathcal{P}\right] = 0$$
$$a^{-3}\frac{\partial[\rho a^3]}{\partial t} = -3\frac{\dot a}{a}\mathcal{P}$$

ขั้นที่หนังสือข้าม — (2.53) ถึง (2.56)

ที่ $\nu = 0$: พจน์แรกเหลือ $\partial_t T^0{}_0 = -\dot\rho$ (เพราะ $T^i{}_0 = 0$) · พจน์ที่สอง $\Gamma^\mu{}_{0\mu}T^0{}_0$: $\Gamma^i{}_{0i}$ บวกสามตัวได้ $3\dot a/a$ คูณ $-\rho$ · พจน์ที่สาม $-\Gamma^\alpha{}_{0\mu}T^\mu{}_\alpha$: ไม่ศูนย์เฉพาะ $\alpha = \mu = i$ ได้ $-3(\dot a/a)\mathcal{P}$ · รวม $-\dot\rho - 3(\dot a/a)\rho - 3(\dot a/a)\mathcal{P} = 0$ คูณ $-1$ ได้ (2.55)

สำหรับ (2.56): กระจาย $a^{-3}\partial_t(\rho a^3) = \dot\rho + 3(\dot a/a)\rho$ (product rule) แทนใน (2.55) จะเหลือ $-3(\dot a/a)\mathcal{P}$ ทางขวา ✓

ผลทันที: matter ไม่มีความดัน ⇒ $\partial(\rho_m a^3)/\partial t = 0$ (2.57) ⇒ $\rho_m \propto a^{-3}$ · radiation มี $\mathcal{P} = \rho/3$ (โจทย์ข้อ 14) ⇒ $\partial(\rho_r a^4)/\partial t = 0$ (2.58) ⇒ $\rho_r \propto a^{-4}$ — ตรงกับการให้เหตุผลแบบมือเปล่าของบทที่ 1

สถิติของอนุภาค (หน้า 38–39). เพื่อเขียน $\rho$ และ $\mathcal{P}$ ด้วยอุณหภูมิ ต้องมี distribution function $f(\vec x, \vec p)$ = จำนวนอนุภาคเฉลี่ยในหนึ่ง "ช่อง" ของ phase space (ตำแหน่ง × โมเมนตัม) หลักความไม่แน่นอนบอกว่าช่องหนึ่งเล็กที่สุดได้ $(2\pi\hbar)^3$ (รูป 2.4: ตาราง $x$–$p$ หนึ่งมิติ แต่ละช่องมีพื้นที่ $2\pi\hbar$ ก้อนแรเงา $dx\,dp$ ครอบเก้าช่อง) จำนวนช่องใน $d^3x\,d^3p$ จึงเป็น $d^3x\,d^3p/(2\pi\hbar)^3$

$$\rho_i = g_i\int\frac{d^3p}{(2\pi)^3}\,f_i(\vec x, \vec p)\,E(p)$$

อ่านว่า $i$ = ชนิดของอนุภาค · $g_i$ = degeneracy (จำนวนสถานะภายใน เช่น spin; โฟตอน $g = 2$) · $E(p) = \sqrt{p^2 + m^2}$ · กลับไปใช้ $\hbar = 1$ · $p$ ในที่นี้คือโมเมนตัมจริง (proper) ที่ลดตามการขยาย ไม่ใช่ $\vec P$ บนกริดของ (2.24) (เชิงอรรถ 4)

$$f_{\rm BE} = \frac{1}{e^{(E-\mu)/T} - 1}$$
$$f_{\rm FD} = \frac{1}{e^{(E-\mu)/T} + 1}$$

อ่านว่า ใน equilibrium ที่อุณหภูมิ $T$: boson (โฟตอน) ใช้ Bose–Einstein ($-1$) และ fermion (อิเล็กตรอน, neutrino) ใช้ Fermi–Dirac ($+1$) · $\mu$ = chemical potential — ตัวปรับที่คุมจำนวนอนุภาค ถ้าจำนวนไม่ถูกอนุรักษ์ (สร้าง/ทำลายได้อิสระ) จะได้ $\mu = 0$ · สังเกต: เมื่อ $E - \mu \gg T$ ทั้งสองแบบลดรูปเป็น $e^{-(E-\mu)/T}$ (สถิติ Boltzmann — บทที่ 3 ใช้มาก) · $+1$ ทำให้ $f_{\rm FD} \le 1$ เสมอ (Pauli: ช่องหนึ่งมี fermion ได้ไม่เกินหนึ่ง) · ในเอกภพเรียบ $f$ ขึ้นกับขนาด $p$ เท่านั้น ไม่ขึ้นกับตำแหน่งหรือทิศ

$$\mathcal{P}_i = g_i\int\frac{d^3p}{(2\pi)^3}\,f_i(\vec x, \vec p)\,\frac{p^2}{3E(p)}$$
$$\frac{\partial\mathcal{P}_i}{\partial T} = \frac{\rho_i + \mathcal{P}_i}{T}$$

อ่านว่า (2.62) ความดันเป็นค่าเฉลี่ยของ $p^2/3E$ (สำหรับอนุภาคไร้มวล $E = p$ ได้ $p/3$ ⇒ $\mathcal{P} = \rho/3$ ทันที) · (2.63) ใช้ได้เมื่อ $\mu \ll T$ จน $f$ ขึ้นกับ $E/T$ อย่างเดียว (พิสูจน์ทั่วไปในโจทย์ข้อ 14) · ตรวจกรณีไร้มวล: $\rho = cT^4$, $\mathcal{P} = cT^4/3$ ⇒ ซ้าย $= 4cT^3/3$, ขวา $= (4cT^4/3)/T$ ✓

$$s \equiv \frac{\rho + \mathcal{P}}{T} \ \propto\ a^{-3}$$

ขั้นที่หนังสือข้าม — ทำไม entropy density ลดแบบ $a^{-3}$ (2.64–2.65)

เขียน (2.56) ใหม่เป็น $a^{-3}\partial_t[(\rho + \mathcal{P})a^3] - \partial_t\mathcal{P} = 0$ (บวกลบ $\partial_t\mathcal{P}$) · ใช้ chain rule $\partial_t\mathcal{P} = \dot T\,\partial\mathcal{P}/\partial T$ แล้วแทน (2.63) ได้ $\dot T(\rho+\mathcal{P})/T$ · ซ้ายมือทั้งก้อนจึงเป็น $a^{-3}\partial_t[(\rho+\mathcal{P})a^3] - (\dot T/T)(\rho+\mathcal{P})$ ซึ่งเท่ากับ $a^{-3}T\,\partial_t[(\rho+\mathcal{P})a^3/T]$ (กระจายอนุพันธ์ของผลหารแล้วเทียบ — สคริปต์ตรวจแล้ว) · ดังนั้น $sa^3$ คงที่ · ใช้กับผลรวมทุกชนิดได้ แม้อุณหภูมิต่างกัน (เชิงอรรถ 5: ถ้ามี $\mu$ จะมีพจน์เพิ่ม แต่ยังลดแบบ $a^{-3}$)

อินทิแกรนด์ไม่ขึ้นกับทิศ ⇒ $d^3p = 4\pi p^2dp$ · ได้ $\rho_\gamma = \tfrac{8\pi}{(2\pi)^3}\int_0^\infty \tfrac{p^3dp}{e^{p/T}-1}$ · แทน $x = p/T$ ($dp = T\,dx$) ได้ $\tfrac{8\pi T^4}{(2\pi)^3}\int_0^\infty\tfrac{x^3dx}{e^x - 1}$ (2.68) · อินทิกรัลมีค่า $6\zeta(4) = \pi^4/15$ ($\zeta$ = Riemann zeta function — ใช้เป็นสูตรสำเร็จ) · คูณกัน: $\tfrac{8\pi}{8\pi^3}\cdot\tfrac{\pi^4}{15} = \tfrac{\pi^2}{15}$ ✓ · และเพราะ $\rho_\gamma \propto a^{-4}$ จึงได้ $T \propto a^{-1}$

$$\frac{\rho_\gamma}{\rho_{\rm cr}} = \frac{\pi^2}{15}\left(\frac{2.725\,{\rm K}}{a}\right)^4\frac{1}{8.098\times10^{-11}h^2\,{\rm eV}^4} = \frac{2.47\times10^{-5}}{h^2a^4}$$

อ่านว่า หารทุกความหนาแน่นด้วย $\rho_{\rm cr}$ (ค่าคงตัวของวันนี้ — เชิงอรรถ 6) ให้เทียบกันง่าย · $8.098\times10^{-11}h^2$ eV⁴ คือ (1.6) เขียนในหน่วยธรรมชาติ · แปลง K เป็น eV ด้วย 11605 K = 1 eV · ยังไม่มีการกระเพื่อม — $\rho_\gamma$ ขึ้นกับเวลาผ่าน $a$ แต่ไม่ขึ้นกับตำแหน่ง

§2.4.2 Baryons (หน้า 41–42). baryon (หนังสือนับอิเล็กตรอนรวมไปด้วย เพราะมวลน้อยมาก — เชิงอรรถ 7) ไม่มี chemical potential เป็นศูนย์ จึงต้องวัดความหนาแน่นตรง ๆ

$$\frac{\rho_b}{\rho_{\rm cr}} = \Omega_b a^{-3}$$

อ่านว่า $\Omega_b$ = ความหนาแน่น baryon วันนี้หารด้วย $\rho_{\rm cr}$ · วิธีวัดสี่ทาง: แก๊สในกลุ่มดาราจักร, การดูดกลืนในสเปกตรัม quasar, CMB anisotropy, และธาตุเบา ซึ่งให้ $\Omega_bh^2 = 0.0205 \pm 0.0018$ (ทั้งหมดค่าปี 2003) — ทุกวิธีให้ baryon ราว 2–5% ของ critical density

§2.4.3 Matter (หน้า 42–44). วิธีที่ไม่พึ่งการเปล่งแสง คือวัดสนามโน้มถ่วงแล้วอนุมานมวล รูป 2.5 (แกนนอนสเกล $R$ เป็น Mpc, แกนตั้งอัตราส่วนมวลต่อแสง, จุดจากดาราจักรถึง supercluster) แสดงว่าอัตราส่วนแบนลงเมื่อเกินราว 1 Mpc สอดคล้องกับ $\Omega_m \simeq 0.3$ วิธีอื่น (power spectrum ของดาราจักร, สนามความเร็ว, สัดส่วนแก๊สในกระจุก, CMB) ให้ค่าใกล้กัน (ค่าปี 2003)

$$\rho_m = \Omega_m\rho_{\rm cr}a^{-3}$$

อ่านว่า $\Omega_m$ รวม baryon และ dark matter · baryon ~5% แต่ matter ~30% ⇒ ส่วนใหญ่ของ matter ไม่ใช่ baryon คือ dark matter

§2.4.4 Neutrinos (หน้า 44–47). ยังไม่มีใครวัด neutrino ของจักรวาลได้ แต่เหตุผลทางทฤษฎีแน่นหนา: neutrino เคยอยู่ใน equilibrium (การกระจายเป็น Fermi–Dirac, $\mu = 0$) แล้วหลุดออกเพราะปฏิกิริยาอ่อน หลังหลุดอุณหภูมิมันยังลดแบบ $a^{-1}$ · จุดที่ซับซ้อนคือ $e^+e^-$ สลายตัวหลังจาก neutrino หลุดไปแล้วเล็กน้อย พลังงานจึงตกไปที่โฟตอนอย่างเดียว ⇒ โฟตอนร้อนกว่า neutrino เครื่องมือคือ $sa^3$ คงที่ (2.66) โดยแต่ละสถานะ spin ของ boson ไร้มวลให้ entropy $2\pi^2T^3/45$ และของ fermion ให้ $7/8$ ของนั้น (โจทย์ข้อ 17)

$$s(a_1) = \frac{2\pi^2}{45}T_1^3\left[2 + \frac78(2 + 2 + 3 + 3)\right] = \frac{43\pi^2}{90}T_1^3$$
$$s(a_2) = \frac{2\pi^2}{45}\left[2T_\gamma^3 + \frac78\,6T_\nu^3\right]$$
$$\frac{T_\nu}{T_\gamma} = \left(\frac{4}{11}\right)^{1/3}$$

ขั้นที่หนังสือข้าม — นับ degree of freedom และแก้ (2.75)

ก่อนสลาย ($a_1$): boson = โฟตอน 2 · fermion = $e^-$ 2, $e^+$ 2, $\nu$ 3 (สามรุ่น รุ่นละหนึ่ง spin), $\bar\nu$ 3 รวม 10 · $2 + \tfrac78\cdot10 = \tfrac{43}{4}$ คูณ $\tfrac{2\pi^2}{45}$ ได้ $\tfrac{43\pi^2}{90}$ ✓

หลังสลาย ($a_2$): เหลือโฟตอน 2 ที่ $T_\gamma$ และ neutrino 6 ที่ $T_\nu$ · ตั้ง $s(a_1)a_1^3 = s(a_2)a_2^3$ แล้วตัด $2\pi^2/45$: $\tfrac{43}{4}(a_1T_1)^3 = [2T_\gamma^3 + \tfrac{21}{4}T_\nu^3]a_2^3$ · neutrino ไม่ได้รับพลังงาน จึง $a_1T_1 = a_2T_\nu$ · ตัด $(a_2T_\nu)^3$: $\tfrac{43}{4} - \tfrac{21}{4} = 2(T_\gamma/T_\nu)^3$ ⇒ $(T_\gamma/T_\nu)^3 = \tfrac{11}{4}$ ✓ (หนังสือเขียนขั้นกลางเป็น (2.75) ซึ่งคือสมการเดียวกันคูณ 2)

$$\rho_\nu = 3\,\frac78\left(\frac{4}{11}\right)^{4/3}\rho_\gamma$$
$$\Omega_\nu \equiv \frac{\rho_\nu}{\rho_{\rm cr}}\bigg|_{\rm today} = \frac{1.68\times10^{-5}}{h^2} \qquad m_\nu = 0$$

อ่านว่า ตัวคูณมาจากสี่เรื่อง: $g_\nu = 6$ เทียบ $g_\gamma = 2$ ให้ 3 · Fermi–Dirac ได้ $7/8$ ของ Bose · อุณหภูมิต่ำกว่าด้วย $(4/11)^{1/3}$ และ $\rho \propto T^4$ ให้กำลัง $4/3$ · รวม $\approx 0.681\rho_\gamma$ (ต่อหนึ่งชนิดราว $0.23\rho_\gamma$ ตามที่สรุปหน้า 52) · $\Omega_\nu$ ใช้ได้เมื่อ neutrino ไร้มวล

$$\rho_\nu = 2\int\frac{d^3p}{(2\pi)^3}\frac{\sqrt{p^2 + m_\nu^2}}{e^{p/T_\nu} + 1}$$
$$\Omega_\nu = \frac{m_\nu}{94h^2\,{\rm eV}} \qquad m_\nu \ne 0$$

อ่านว่า neutrino มีมวลจริง (หลักฐานจาก oscillation; อย่างน้อยหนึ่งตัวหนักกว่า 0.05 eV — ค่าปี 2003) · (2.79) คือพลังงานของหนึ่งรุ่นที่มีมวล $m_\nu$ · ตอนร้อน ($T_\nu \gg m_\nu$) ทำตัวเหมือนไร้มวล · ตอนเย็น ($T_\nu \ll m_\nu$) $\rho_\nu = m_\nu n_\nu$ โดย $n_\nu = 3n_\gamma/11$ (โจทย์ข้อ 18) ได้ (2.80) · รูป 2.6 (แกนนอน $T_\nu/m_\nu$ จาก 10 ลงถึง 0.01, แกนตั้ง $\rho_\nu/\rho_\gamma$) แสดงการเปลี่ยนผ่านรอบ $T_\nu \sim m_\nu$

§2.4.5 Dark Energy (หน้า 47–50). หลักฐานสองชุด: (ก) งบไม่ลง — ความหนาแน่นรวมใกล้ critical (คาดจากทฤษฎีในบทที่ 6 และเห็นใน CMB บทที่ 8) แต่ matter มีแค่ราวหนึ่งในสาม ส่วนที่เหลือต้องเป็นของที่เรียบไม่จับกลุ่ม; (ข) supernova ปี 1998 — ระยะ $d_L$ ที่ $z$ สูงยาวเกินกว่าที่ matter อย่างเดียวจะให้ได้ (เชิงอรรถ 11 เล่าเรื่องการตั้งชื่อ: cosmological constant, quintessence, dark energy)

$$m - M = 5\log\!\left(\frac{d_L}{10\,{\rm pc}}\right) + K$$

อ่านว่า $m$ = apparent magnitude (ความสว่างที่เห็น) · $M$ = absolute magnitude (ความสว่างจริง) · magnitude ยิ่งมากยิ่งมืด · $\log$ ฐานสิบ · pc = parsec · $K$ = K-correction ชดเชยที่สเปกตรัมเลื่อนเข้าออกช่วงที่วัด · เลข 5 มาจาก $m = -\tfrac52\log F$ และ $F \propto d_L^{-2}$

ตัวอย่างคิดเล่นในหนังสือ: supernova สองดวงที่สว่างจริงเท่ากัน ดวงหนึ่ง $z = 0.83$, $m = 24.32$ อีกดวง $z = 0.026$, $m = 16.08$ · ดวงใกล้ใช้ $d_L = z/H_0$ ได้ (2.82) แล้วแก้ได้

$$H_0\,d_L(z = 0.83) = 1.16$$

ขั้นที่หนังสือข้าม — ตัวเลขของ (2.82)–(2.83)

$24.32 - 16.08 = 8.24 = 5\log(d_L^{\rm far}/d_L^{\rm near})$ ⇒ อัตราส่วน $= 10^{1.648} \approx 44.5$ · คูณ $H_0d_L^{\rm near} = 0.026$ ได้ $\approx 1.16$ ✓ · เทียบทฤษฎี: flat + matter ล้วน ใช้ (2.43) กับ (2.50) ได้ $H_0d_L = 2(1+z)[1 - (1+z)^{-1/2}] \approx 0.95$ · flat กับ $\Omega_m = 0.3$, $\Omega_\Lambda = 0.7$ ต้องอินทิเกรต (2.89) เชิงตัวเลขได้ $\approx 1.23$ · ข้อมูลใกล้แบบหลังกว่า (สคริปต์ตรวจทั้งสามค่า)

รูป 2.7 (ระนาบ $\Omega_m$–$\Omega_\Lambda$ มีพื้นที่ที่ข้อมูลยอมรับ เส้นทแยงคือเอกภพ flat) ตัด flat matter ล้วนออก และตัด open ที่ไม่มี $\Lambda$ ด้วย ผู้เขียนวิจารณ์ว่ารูปนี้ให้อิสระผิดที่ (ยอมให้ทั้งโค้งและมี $\Lambda$) แต่ไม่ให้ dark energy ชนิดอื่น จึงนิยาม equation of state

$$w \equiv \frac{\mathcal{P}}{\rho}$$
$$\rho_{\rm de} \propto \exp\left\{-3\int^a\frac{da'}{a'}\left[1 + w(a')\right]\right\}$$

อ่านว่า cosmological constant $w = -1$ (ความดันติดลบเท่ากับ $\rho$ จึงจะไม่เจือจาง) · matter $w = 0$ · radiation $w = 1/3$ · (2.85) ได้จากอินทิเกรต (2.55) · $w$ คงที่ให้ $\rho \propto a^{-3(1+w)}$ ซึ่งคืน $a^{-4}, a^{-3}, a^0$ ตามลำดับ · รูป 2.8 (แกนนอน $\Omega_M$, แกนตั้ง $w$, contour 68–99%) บอกว่า $w$ มากกว่าราว $-0.5$ ไม่น่าเป็นไปได้ (ค่าปี 2003)

ขั้นที่หนังสือข้าม — (2.55) ⇒ (2.85)

แทน $\mathcal{P} = w\rho$ ใน (2.55) และเปลี่ยนตัวแปรเวลาเป็น $a$ ด้วย $\partial_t = \dot a\,\partial_a$: $\dot a\,d\rho/da + (\dot a/a)3(1+w)\rho = 0$ · ตัด $\dot a$: $d\ln\rho/da = -3(1+w)/a$ · อินทิเกรตแล้วยกกำลัง $e$ ได้ (2.85)

§2.4.6 Epoch of Matter–Radiation Equality (หน้า 50–51). การกระเพื่อมโตต่างกันในยุค radiation กับ matter จึงต้องรู้ว่าเปลี่ยนยุคเมื่อไร รวม radiation = โฟตอน (2.70) + neutrino ไร้มวล (2.78)

$$\frac{\rho_r}{\rho_{\rm cr}} = \frac{4.15\times10^{-5}}{h^2a^4} \equiv \frac{\Omega_r}{a^4}$$
$$a_{\rm eq} = \frac{4.15\times10^{-5}}{\Omega_mh^2}$$
$$1 + z_{\rm eq} = 2.4\times10^4\,\Omega_mh^2$$

อ่านว่า $4.15 = 2.47 + 1.68$ · ตั้ง (2.86) = (2.72)/$\rho_{\rm cr}$ คือ $4.15\times10^{-5}/(h^2a^4) = \Omega_m/a^3$ แก้ได้ $a_{\rm eq}$ · $1 + z = 1/a$ · matter มากขึ้น ⇒ equality เร็วขึ้น · สิ่งที่ต้องจำ: $z_{\rm eq}$ มากกว่า $z$ ตอนโฟตอนหลุด ($z_* \simeq 10^3$) หลายเท่า ⇒ CMB หลุดในยุค matter แล้ว

§2.5 Summary · หน้า 51–52

สรุปใหม่สองสูตรที่ใช้บ่อยที่สุดในบทหลัง: comoving distance ในรูป redshift และ conformal time

$$\chi(z) = \int_0^z\frac{dz'}{H(z')}$$
$$\eta = \int_0^t\frac{dt'}{a(t')} = \int_z^\infty\frac{dz'}{H(z')}$$

อ่านว่า ได้จาก (2.42) และ (2.41) โดยเปลี่ยนตัวแปร $a = 1/(1+z)$, $da = -dz/(1+z)^2$ ซึ่งทำให้ $da/a^2 = -dz$ พอดี (เครื่องหมายลบกลับขอบเขต) · ที่เหลือของ summary ทวนตัวเลขบัญชีพลังงาน: neutrino ไร้มวลหนึ่งชนิด $= 0.23\rho_\gamma$, $\Omega_bh^2 = 0.0205 \pm 0.0018$, $\Omega_m \simeq 0.3$, $\Omega_{\rm de} \simeq 0.7$ (ค่าปี 2003)
